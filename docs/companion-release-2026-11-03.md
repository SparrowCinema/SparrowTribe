# 影迷护照更新验收

以主分支 47560c4（含 #111–#115 的金马片单、活动独立页、返回位置恢复和官方头图）为基础。保留已有片目与场次、用户存储键、分享链接与日历 UID。

## 最终界面

- 片目使用专题 / 城市 / 我的检索栏，城市与个人分类组合生效，下一场与排序使用当前城市和专题。
- 时间轴在前、清单在后，以图标切换。清单保留原场次行，按影院、影厅分组；影院标题采用纸色与青绿色细边，加入排片始终在右侧。时间轴保留首场前约半小时空白。
- 影片详情保持原先两栏及章节顺序。内容提示在放映场次之后，标题与上下章节对齐，正文放进同宽纸色卡片，提示说明折叠。原有看点中补入选片笔记。
- 网站“我的”合成一个连续菜单；护照封面可展开，首页近期行程不在此重复。指南、反馈、同步与其余入口使用相同图标、字列和分隔线。
- 完整 JSON 备份、合并导入、云端内容清空及本地与云端归属说明。备份不包含同步码；云端清空保留本机与删除标记，不冒充彻底注销。

## 内容核对范围

原 120 部影片补双语内容提示与独立选片笔记：116 部依据既有剧情简介核对，4 部结合官方海外内容提示（证据见 content-review-2026-11.json）。这不是逐帧审片；光敏提示仅 Moonage Daydream 已查实，其他保留未核实说明。10 部有已核实的美国发行版本 MPA 分级，其余不显示未知破折号或猜测分级。

并入主分支时新增的金马 156 部尚未完成情节内容审查，均明确标记 pending 并提供待核实说明；不能将它们宣传为内容已审查。未来新增影片由部署校验强制要求提示状态、说明、双语层。
